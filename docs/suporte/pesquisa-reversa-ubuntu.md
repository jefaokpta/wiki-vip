# Pesquisa Reversa

A pesquisa reversa permite localizar qualquer comando executado anteriormente no terminal, agilizando tarefas recorrentes.

## Como utilizar

Pressione `CTRL+R` para abrir a pesquisa reversa.

![Pesquisa reversa no Ubuntu](../../assets/img/suporte/pesquisa-reversa-ubuntu/pesquisa-reversa.png "Pesquisa reversa no Ubuntu")

No Marte, é comum usar o celular para monitorar chamadas. Nesse caso, pressione `CTRL+R` e informe qualquer número do celular. No exemplo abaixo, foi digitado `5268` e o terminal retornou o comando:

```bash
sudo rasterisk | egrep "52681079"
```

Depois de localizar o comando, pressione `ENTER`, a seta para a direita ou a seta para a esquerda e o resultado será considerado como comando, poupando a digitação do comando completo.

![Resultado da pesquisa reversa](../../assets/img/suporte/pesquisa-reversa-ubuntu/resultado-pesquisa-reversa.png "Resultado da pesquisa reversa")
